# Cloud Computing Concepts Reflection

Cloud computing is already part of my everyday life because I use different applications that rely on cloud technology. These services help me store information, communicate with other people, and finish my school tasks more easily. Three cloud services that I commonly use are Google Drive, Facebook Messenger, and Canva.

Google Drive is one of the cloud services I use for saving and organizing my files. It is an example of **Software as a Service (SaaS)** because I can use its features online without installing or managing the system behind it. It follows the **Public Cloud** deployment model because anyone with a Google account can access the service through the internet.

Facebook Messenger is another cloud-based application that I use for communication. It is also considered **SaaS** because it provides messaging and calling features through an online platform. It uses a **Public Cloud** deployment model because it is available to many users around the world and is managed by the service provider.

Canva is a cloud service that I use when creating presentations, posters, and other designs for school. It is also an example of **SaaS** because users can access design tools online without needing to install complicated software. Canva uses a **Public Cloud** model because users can access it anytime using the internet.

Version control is important when working with cloud projects because it helps keep track of changes made to files and systems. It prevents losing important work and makes it easier to fix mistakes by checking previous versions. Git and GitHub help teams work together by allowing members to share files, update projects, and review changes before applying them. They also reduce errors because every update is recorded. Learning Git and GitHub is useful because these tools are commonly used in real-world software development and cloud-based projects.
